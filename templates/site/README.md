# templates/site: stage 0 of the website / Stufe 0 der Website

**DE.** Vorlage und Platzhalterseiten fuer freesynergy.net, helfa.org, freeplanetearth.org (Zentinel `static-files`). Keine Geheimnisse. Die Seiten sind neutral ("im Umbau", de/en, Wurzel mit sichtbarer Sprachwahl); **TODO (Nutzer):** echte Inhalte, Impressum, Datenschutz. Nichts davon ist erfunden.
Ablauf (Mensch fuehrt aus, keine KI auf dem Server): `site-bauen` -> `site-signieren` (Freigabe-Beleg) -> Mensch liefert aus. Zentinel nur aus dem signierten Mirror-Release (fs-zentinel v26.11_2, .deb + .asc), danach `render.sh --staging --install-pages`, `zentinel test -c`, Start; erst nach sauberem Staging `--production` (ACME-Zustand leeren, siehe fs-zentinel `examples/README.md`). Port 80 liefert je Host eine Seite mit Meta-Refresh und Link auf https (eigene Loesung, kein echter Redirect).
Test lokal: `test-podman.sh` (Podman, nur 127.0.0.1, kein Netz); mit `ZENTINEL_DEB` und `BASE_IMAGE` gegen das .deb. Selbsttests: `scripts/test-site.sh`.
