- Conditions of the review: sign job rebuilds from the approved git state and compares byte for byte before the key is loaded (the checks run without the key in their environment); the approval pins the signing SUBKEY fingerprint, is valid 72 hours from the SIGNATURE time, carries `mode`; in CI the run id must be `<id>-<attempt>` of an earlier run; the three surviving mutations are tests now (`call: auto-approve` instead of the person's listen, `${ $secrets ... }` in the build job, switched-off byte comparison against a changed copy of the script); the step `same-bytes` is gone (it could never be red), `signatures-check` is a real script. Texts: podman script header, outdated redirect statements in the template.
- Port 80 is a real 301 (namespace listener plus redirect filter), the meta-refresh page is dropped. Measured with 26.11_2 on a high port (GET, HEAD, POST): 301 to the same host and path, query string lost. Not proven until the staging run: ACME HTTP-01 on that listener, IPv6. `render.sh --http-only` for the first start without ACME. Content-Security-Policy is a setting per site (`CSP_MODE1..3`, `CSP1..3`, strict default, `passthrough` preset warns); measured with 26.11_2: the route `response-headers` are NOT sent for `static-files` routes, so the setting is written but not delivered yet (upstream request pending).

Not proven: the real ACME run, TLS, the `@fs` names of the new steps (`site-rebuild-compare`, `site-build`, ...), a runtime run of the flows and of `site.yml` (no GitHub run, no environment, no keys exist yet), that the approval subkey is unusable for agents.
- `site.toml` (schema 1, `templates/site/site-toml-schema.md`): the ONE place of the host names of a site, at the root of the signed package (names primary + aliases, wanted DNS record types A/AAAA/CAA, `acme.method` http-01 with dns-01 reserved, CSP mode/policy). All bypasses of the review are test cases (red), five mutations on a copy turn them green. `render.py` refuses a passthrough site without `--allow-passthrough` and says in a NOTE (static) and in the KDL head that the CSP header is not delivered in 26.11_2.
